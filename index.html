I'm a Computer Science student who likes taking software apart to understand how it holds together, then rebuilding it a little better. Most of my time goes into backend systems — the parts of an application that quietly do the heavy lifting while the interface gets the applause.

Python is where I'm most comfortable, and Flask is usually where my ideas start turning into working applications. I care about writing code that's readable six months later, not just code that runs today, which is why data structures and clean logic matter as much to me as shipping features.

Outside of coursework, I contribute to open source when I can and treat every small project as practice for a larger one. I'd rather learn by building something real than by reading about it indefinitely.
